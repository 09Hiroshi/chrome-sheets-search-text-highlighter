# シート検索文字ハイライト

検索結果パネルは表示しません。検索中の語は、DOM上で正確な文字範囲を取得できる編集欄や数式バーに限って、背景色でハイライトします。セルのデータや書式は変更しません。

## 更新

1. Chrome で `chrome://extensions` を開きます。
2. この拡張機能カードの更新ボタンを押します。
3. Google スプレッドシートのタブを再読み込みします。

## 制限

Google スプレッドシートの通常表示セルはCanvas描画のため、セル内の文字単位の正確な位置をDOM範囲として取得できません。検索結果セルにはGoogle標準の選択枠が表示されます。数式バーがinput/textareaの場合も部分範囲を直接装飾できません。これらの場合は誤った位置に色を塗らないよう、文字ハイライトは行いません。
