# シート検索文字ハイライト

検索結果パネルは表示しません。検索中の語は、DOM上で正確な文字範囲を取得できる編集欄や数式バーに限って、背景色でハイライトします。セルのデータや書式は変更しません。

## 初回インストール

1. GitHubの **Code → Download ZIP** からダウンロードし、展開します。
2. Chrome で `chrome://extensions` を開き、「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、`manifest.json` があるフォルダを選びます。
4. Google スプレッドシートのタブを再読み込みします。

## 更新

1. GitHubから最新版を取得します（Gitを使う場合は `git pull`）。
2. `chrome://extensions` でこの拡張機能カードの更新ボタンを押します。
3. Google スプレッドシートのタブを再読み込みします。

## 制限

Google スプレッドシートの通常表示セルはCanvas描画のため、セル内の文字単位の正確な位置をDOM範囲として取得できません。検索結果セルにはGoogle標準の選択枠が表示されます。数式バーがinput/textareaの場合も部分範囲を直接装飾できません。これらの場合は誤った位置に色を塗らないよう、文字ハイライトは行いません。
